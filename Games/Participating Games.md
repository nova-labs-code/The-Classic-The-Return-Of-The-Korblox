Participating games are Roblox experiences that join the event and host quests for players.

Each game should provide a unique part of the event while connecting to the overall story.

---

## Purpose

Participating games allow players to explore different worlds while progressing through the event.

Each game can represent a different part of the classic Roblox timeline.

---

## Developer Requirements

Every participating game must meet the event requirements.

Requirements:

- At least 500,000 lifetime visits
- A playable and active experience
- A good reputation with players
- At least one event quest
- A clear objective
- A badge reward
- A classic Roblox feeling

See:
[Game Requirements](Game%20Requirements.md)

---

## Quest Integration

Games can include:

- Exploration quests
- Obby challenges
- Boss battles
- Collecting quests
- Puzzle challenges
- Hidden secrets

Each quest should reward players with event progression.

Possible rewards:
- [Tixs](../Gameplay%20Systems/Tixs%20System.md)
- [Builder Tokens](../Gameplay%20Systems/Builder%20Tokens%20System.md)
- Event badges

---

## Story Connection

Each game should explain how it connects to the Korblox invasion.

Examples:

- A classic world being attacked by Korblox
- A builder location needing repairs
- A lost Tix location being recovered
- A hidden area containing a secret
- A Korblox-controlled area that players must reclaim

---

## Developer Benefits

Participating developers can receive:

- Event exposure
- Player discovery
- Community recognition
- Special event participation badge
- A chance to be featured as part of the event
