Developer communication explains how event organizers and participating developers work together.

## Purpose

Clear communication helps every participating game create a consistent event experience.

Website:

- Event announcements
- Developer communication
- Technical support
- Testing coordination
- UGC planning
- Community discussions

## Event Communication Groups

The communication system is organized into groups so discussions stay focused.

---

## 📢 Event Staff

Purpose:

Official event organization and management.

Used for:

- Official announcements
- Planning discussions
- Event decisions
- Developer coordination
- Release planning

Access:

Event organizers and staff only.

---

## 🛠 Developers

Purpose:

Communication between approved participating developers.

Used for:

- Quest discussions
- Technical support
- Integration questions
- Development progress
- Event updates
- Collaboration with other developers

Access:

Approved developers only.

Requirements:

- Accepted [Developer Application](../Development/Developer%20Application)
- Participating experience
- Meets all [Game Requirements](Game%20Requirements)

---

## 🎨 UGC Creators

Purpose:

Communication for creators designing event rewards.

Used for:

- UGC concepts
- Asset discussions
- Design reviews
- Feedback
- Final approvals

Access:

Approved UGC creators and event staff.

Related:

[Builder Token UGC Rewards](../Rewards/Builder%20Token%20UGC%20Rewards)

## 🧪 Testers

Testing every part of the event before launch.

- Badge testing
- Reward verification
- Gameplay feedback

Access:

Approved testers and event staff.

[Testing Plan](../Development/Testing%20Plan)

If changes are required, developers receive:

- Review results
- Required changes
- Technical recommendations

---

## Launch Coordination

Before release, developers confirm:

- Quests are complete
- Tix Badge works correctly
- Builder Token Badge works correctly
- Rewards are configured
- Event update has been published

---

## Post-Launch Communication

After release, developers can report:

- Bugs
- Player feedback
- Reward issues
- Quest issues
- Exploits
- Balance concerns
