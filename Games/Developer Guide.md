Developers who participate in The Classic: The Return of Korblox help create the event experience.

---

## Joining The Event

Developers must submit their experience for review.

Requirements:

- Experience has at least 500,000 lifetime visits
- Experience matches the event theme
- Developer can create an event quest
- Developer can support event badges

---

## Creating A Quest

Each developer should create a quest connected to their game.

Quest examples:

- Complete a classic obstacle course
- Find hidden items
- Defeat a boss
- Explore a special area
- Complete a challenge

---

## Event Integration

Developers provide:

- Quest location
- Quest requirements
- Badge information
- Reward information

---

## Theme Guidelines

Games should feel like part of Roblox history.

Recommended themes:

- Classic adventures
- Building
- Exploration
- Obbies
- Battles
- Community experiences

---

## Review Process

Games will be reviewed for:

- Quality
- Player experience
- Theme connection
- Quest design
- Technical readiness
