## Reward and Badge Requirements

Each participating experience must provide:

- 1 Tix reward
- 1 Builder Token reward
- 2 event badges

The badges are connected to the two event currencies.

---

## Tix Badge

Purpose:

Rewards players for completing the easier event quest.

Requirement examples:

- Complete the main event quest
- Explore the game
- Find classic items
- Complete a simple challenge

Reward:

- Tixs

Used for:

[Classic Clothing Rewards](../Rewards/Classic%20Clothing%20Rewards)

---

## Builder Token Badge

Purpose:

Rewards players for completing a harder challenge.

Requirement examples:

- Complete a difficult challenge
- Defeat a boss
- Find a secret area
- Complete an advanced quest

Reward:

- Builder Tokens

Used for:

[Builder Token UGC Rewards](../Rewards/Builder%20Token%20UGC%20Rewards)

---

## Game Reward Limit

Each participating game can provide:

- 1 Tix badge
- 1 Builder Token badge
- 1 Tix reward
- 1 Builder Token reward

This keeps every game unique while giving players a reason to complete both quests.
