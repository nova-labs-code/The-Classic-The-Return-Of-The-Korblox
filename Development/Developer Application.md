The developer application allows Roblox creators to request participation in The Classic: The Return of Korblox.

---

## Purpose

The application helps select experiences that fit the event and provide a good player experience.

---

## Experience Requirements

Developers must provide:

- Game name
- Experience link
- Developer/group name
- Current visit count
- Description of the experience

---

## Minimum Requirements

The experience must have:

- At least 500,000 lifetime visits
- An active player base
- A playable experience
- Good community reputation
- Ability to support event quests

Related:

[Game Requirements](../Games/Game%20Requirements)

---

## Event Proposal

Developers should explain:

- How their game connects to the story
- What quest they will create
- What area players will visit
- How the Korblox invasion affects their world

---

## Quest Information

Developers provide:

- Quest name
- Quest objective
- Completion requirements
- Badge information
- Reward information

Related:

[Quest System](../Gameplay%20Systems/Quest%20System)

---

## Review Process

Applications are reviewed based on:

- Experience quality
- Theme connection
- Quest design
- Player experience
- Technical readiness

---

## Approval

Approved developers receive:

- Event participation information
- Development guidelines
- Integration instructions
- Release schedule
