The currency system manages the event currencies used for unlocking rewards.

The Classic: The Return of Korblox uses two event currencies:

- [Tixs](../Gameplay%20Systems/Tixs%20System.md)
- [Builder Tokens](../Gameplay%20Systems/Builder%20Tokens%20System.md)

---

# Purpose

The currency system gives players progression goals through quests and challenges.

Players earn currencies by completing event activities.

---

# Tixs

Tixs are the easier currency earned during the event.

Earned from:

- Easy quests
- Tix Badges
- Participating game quests

Used for:

- Classic clothing rewards

Related:

[Tix Shop](../Rewards/Tix%20Shop.md)
[Classic Clothing Rewards](../Rewards/Classic%20Clothing%20Rewards.md)

---

# Builder Tokens

Builder Tokens are the harder currency earned during the event.

Earned from:

- Hard quests
- Builder Token Badges
- Boss challenges
- Difficult objectives

Used for:

- UGC accessory rewards

Related:

[Builder Token Shop](../Rewards/Builder%20Token%20Shop.md)
[Builder Token UGC Rewards](../Rewards/Builder%20Token%20UGC%20Rewards.md)

---

# Currency Flow

Player completes quest

↓

Player earns badge

↓

Badge grants currency

↓

Currency is saved

↓

Player meets reward requirement

↓

Reward unlocks

---

# Saving

The system should save:

- Total Tixs
- Total Builder Tokens
- Reward progress
- Claimed rewards

---

# Security

The system should prevent:

- Fake currency awards
- Duplicate currency rewards
- Currency manipulation
- Unauthorized reward claims

---

# Developer Requirements

Participating games should only award currencies through approved event badges.
