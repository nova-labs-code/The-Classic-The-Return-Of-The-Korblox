Testing ensures the event works correctly before release.

---

## Testing Stages

## Internal Testing

First testing phase.

Test:

- Event systems
- Quest completion
- Currency rewards
- Badge rewards
- Teleport systems

---

## Developer Testing

Participating developers test their own experiences.

Check:

- Quest objectives work
- Badges award correctly
- Rewards are connected
- Players understand the goal

---

## Closed Testing

A small group of players tests the full event.

Check:

- Player progression
- Difficulty balance
- Reward values
- Bugs and issues

---

## Release Testing

Final checks before launch.

Verify:

- All games are working
- All rewards are available
- All badges are functional
- All systems are connected

---

## Bug Tracking

Issues should be recorded with:

- Problem description
- Location
- Steps to reproduce
- Priority
- Status

---

## Testing Goals

The event should provide:

- Fair progression
- Reliable rewards
- Smooth gameplay
- A memorable experience
