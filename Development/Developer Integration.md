Developer integration explains how participating Roblox experiences connect to The Classic: The Return of Korblox.

---

# Purpose

The integration system allows approved developers to add event quests, badges, and rewards while keeping the event consistent.

---

# Game Requirements

Each participating game must provide:

- 1 Easy Quest
- 1 Hard Quest
- 1 Tix Badge
- 1 Builder Token Badge
- 1 Tix reward
- 1 Builder Token reward

Related:

[Game Requirements](../Games/Game%20Requirements)

---

# Integration Process

## Step 1 - Approval

Developer submits:

- Experience information
- Developer information
- Quest ideas

Related:

[Developer Application](Developer%20Application)

---

## Step 2 - Quest Creation

Developer creates:

- Easy quest
- Hard quest
- Quest objectives
- Completion requirements

---

## Step 3 - Badge Setup

Developer creates:

- Tix Badge
- Builder Token Badge

Badges must correctly award the matching currency.

Related:

[Badge System](../Gameplay%20Systems/Badge%20System)

---

## Step 4 - Testing

Verify:

- Quests work
- Badges award correctly
- Rewards connect correctly
- Progress saves correctly

Related:

[Testing Plan](Testing%20Plan)

# Security

The system should prevent:

- Duplicate badge rewards
- Fake currency awards
- Reward duplication
- Exploits
