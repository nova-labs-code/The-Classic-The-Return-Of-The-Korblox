The reward system flow explains how players earn and unlock event rewards.

---

## Overview

The reward system connects quests, badges, currencies, and rewards.

Player progression:

Quest Completion
→ Badge Awarded
→ Currency Earned
→ Reward Requirement Met
→ Reward Unlocked

---

# Tix Reward Flow

Tixs are earned through easier event quests.

Flow:

Player completes easy quest
→ Player earns Tix Badge
→ Player receives Tixs
→ Player saves Tixs
→ Player unlocks classic clothing

Related:

[Tix Shop](../Rewards/Tix%20Shop.md)
[Classic Clothing Rewards](../Rewards/Classic%20Clothing%20Rewards.md)

# Builder Token Reward Flow

Builder Tokens are earned through harder event quests.

Flow:

Player completes hard quest
→ Player earns Builder Token Badge
→ Player receives Builder Tokens
→ Player saves Builder Tokens
→ Player unlocks UGC accessory

Related:

[Builder Token Shop](../Rewards/Builder%20Token%20Shop.md)
[Builder Token UGC Rewards](../Rewards/Builder%20Token%20UGC%20Rewards.md)

---

# Participating Game Reward Flow

Each participating game provides:

- 1 Tix Badge
- 1 Builder Token Badge

The badges connect the game quests to the event reward system.

---

# Reward Verification

The system should verify:

- Player owns the required badge
- Player has enough currency
- Player has not already claimed the reward

---

# Saving Data

The system should save:

- Tixs collected
- Builder Tokens collected
- Completed badges
- Owned clothing rewards
- Owned UGC accessories

---

# Anti-Exploit Protection

The system should prevent:

- Duplicate rewards
- Fake badge claims
- Currency manipulation
- Reward duplication
