The event rules keep **The Classic: The Return of Korblox** fair, organized, and enjoyable for everyone.

---

## Player Rules

Players should:

- Complete quests fairly
- Respect other players
- Avoid exploiting
- Avoid abusing glitches
- Follow Roblox Community Standards

---

## Reward Rules

Event rewards must:

- Be earned through official quests
- Require the correct badge
- Only be claimed once
- Save correctly to the player's account

## Participating Game Rules

Games must:

- Meet the event requirements
- Provide exactly 2 event badges
- Provide 1 Tix reward
- Provide 1 Builder Token reward
- Include a classic Roblox feeling

## Developer Rules

Developers must:

- Use approved event systems
- Test quests before release
- Report bugs
- Avoid unfair reward methods

## Exploit Prevention

The event should prevent:

- Fake badge rewards
- Duplicate rewards
- Currency manipulation
- Unauthorized unlocks
