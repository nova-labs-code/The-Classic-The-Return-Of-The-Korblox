The event schedule defines the timeline for The Classic: The Return of Korblox.

---

## Planning Phase

Time before launch dedicated to preparing the event.

Tasks:

- Create event systems
- Design story
- Create quests
- Contact developers
- Create rewards
- Test features

Related:

[Developer Communication](../Games/Developer%20Communication)
[Testing Plan](../Development/Testing%20Plan)

---

## Developer Phase

Participating developers prepare their experiences.

Tasks:

- Create event quests
- Add badges
- Add rewards
- Test integration
- Submit updates

Related:

[Developer Application](../Development/Developer%20Application)

---

## Testing Phase

The event is tested before release.

Tasks:

- Test quests
- Test badges
- Test rewards
- Find bugs
- Improve balance

Related:

[Testing Plan](../Development/Testing%20Plan)

---

## Launch Phase

The event becomes available to players.

Players can:

- Join the event hub
- Complete quests
- Visit participating games
- Collect Tixs
- Earn Builder Tokens
- Unlock rewards

---

## Active Event Period

During the event:

Monitor:

- Player activity
- Developer issues
- Bug reports
- Community feedback

---

## Final Phase

After the event ends:

Tasks:

- Archive event information
- Record results
- Celebrate community participation
- Preserve event history
