## Name

The Classic: The Return of Korblox

## Concept

The Classic: The Return of Korblox is a Roblox community event celebrating classic Roblox culture.

Players are sent back to the classic era where they must stop the Korblox from changing Roblox history.

The event combines:
- Classic Roblox nostalgia
- Quest-based gameplay
- Collectible rewards
- Community-created experiences

---

## Main Features

### Tixs

Players collect [Tixs](../Gameplay%20Systems/Tixs%20System.md) by completing quests and exploring event games.

Tixs are used to unlock classic clothing.

---

### Builder Tokens

Players earn [Builder Tokens](../Gameplay%20Systems/Builder%20Tokens%20System.md) from harder challenges.

Builder Tokens unlock exclusive classic-themed UGC rewards.

---

### Quests

Players complete [quests](../Gameplay%20Systems/Quest%20System.md) across participating games.

Quest types:
- Easy quests
- Hard quests
- Secret quests

---

### Participating Games

Developers can create event experiences that connect to the story.

Requirements:
- Classic Roblox feeling
- Quest integration
- Badge support
- Fair gameplay
